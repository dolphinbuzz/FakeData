Política de Privacidade

Última atualização: 27 de agosto de 2026

Resumo

O FakeData é uma extensão para Chrome e Microsoft Edge que gera dados fictícios para testes de QA. A extensão foi projetada para funcionar localmente e não coleta, armazena ou compartilha dados pessoais.

Dados processados

Os dados gerados, como nomes, documentos, e-mails, telefones e informações de empresas ou veículos, são criados aleatoriamente no navegador. Eles não representam pessoas ou organizações reais e não são enviados para servidores externos.

Permissões

A permissão sidePanel é usada exclusivamente para exibir o gerador na lateral do navegador. A extensão não acessa o conteúdo das páginas, o histórico de navegação, cookies, arquivos ou informações de autenticação.

Serviços de terceiros

A extensão não usa analytics, anúncios, rastreadores, APIs externas ou serviços de terceiros. Os domínios de e-mail exibidos são apenas valores fictícios para testes.

Alterações e contato

Esta política poderá ser atualizada para refletir mudanças na extensão ou na legislação aplicável. Dúvidas podem ser encaminhadas pelo repositório do projeto no GitHub.
